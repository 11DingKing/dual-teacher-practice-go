# 双师型教师实践认证平台

该项目服务于职业本科教师的双师型认定、企业实践、技术服务、实训授课、成果佐证、评价与续认复核。学校人事、二级学院、企业导师、教研负责人和教师在同一条可追溯证据链上协作。

## 运行

```bash
go run .
```

默认监听 `:8080`，提供 `/healthz`、`/readyz` 和 JSON API。数据库启动时自动应用 `migrations/` 下的版本化迁移。

## 主要流程

教师申请 → 学院初审 → 企业实践/技术服务记录 → 证据核验 → 同行与企业评价 → 人事认证 → 年度复核/续认。每一步均有角色权限、幂等键、审计事件和状态转换约束。
